# School Website Demos

Five complete, themed demo websites for one fictional school (Sunrise Public School, Nursery–Class 8, Nipania, Indore) — built with Next.js 14 + Tailwind.

- `/` — showcase landing (pick a design)
- `/beacon` Classic Trust · `/kite` Modern Animated · `/crayon` Warm & Playful · `/regal` Elite Premium · `/slate` Minimal Editorial
- Each theme: Home, About, Academics, Admissions (steps + age criteria + documents), Gallery, Contact + campus-visit WhatsApp booking, Hindi/English toggle

**Rebrand for a client:** edit `lib/config.ts` (name, city, phone, WhatsApp, map).

```bash
npm install
npm run dev
```
